
# Student Grade Manager

A Student Grade Manager application built using Python and Streamlit.

## Features
- Add student names and marks.
- Automatically calculate grades.
- Display student results in a table.
- Calculate class average.
- Show highest and lowest marks.
- Validate marks between 0 and 100.

## Requirements
- Python
- Streamlit
- Pandas

## How to Run

Install the packages:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run grade_app.py
```
